# X Reply Copilot

Chrome / Edge 扩展（Manifest V3）：在 X 上自动浏览时间线，用 DeepSeek 生成回复草稿。**每一条回复都要你在电脑上逐条批准后才会发出。**

## 安装 / 更新

**Windows / macOS / Linux 通用**：同一个包可以在 Chrome、Edge、Brave 等 Chromium 浏览器上使用。

1. 到 [Releases](../../releases) 下载 `x-reply-copilot-vX.Y.Z.zip`，解压到一个固定的文件夹（以后别删、别挪）
2. 打开 `chrome://extensions`（Edge 是 `edge://extensions`），开启「开发者模式」
3. 首次：点「加载已解压的扩展程序」选择解压出来的文件夹；更新：解压新版本覆盖原文件夹，再点扩展卡片上的 ↻
4. **刷新已打开的 x.com 页面**（旧页面里还是旧脚本）
5. 点扩展图标打开设置页，填你自己的 DeepSeek API Key，点「测试 DeepSeek」

API Key 只保存在你本机浏览器里（`chrome.storage.local`），插件只会访问 `api.deepseek.com` 和 x.com。

## 两种回复方式

**单条自选**：帖子操作栏里的「✨ AI回复」→ 生成回复并填进 X 的回复框 → 你检查、修改后自己点「回复」。

**批量**：右下角面板点「▶ 开始自动浏览」，页面自动滚动，匹配关键词的帖子会生成草稿进入面板。每条草稿可以：
- 编辑内容（右下角显示字数，超限标红）
- 勾选「批准」
- 「自己发」：打开回复框/回复页，由你手动点发送
- 「重写」/「忽略」

面板上的「草稿满 N 条自动停止」可以直接改（设置页里也有），待处理草稿达到 N 条时自动停止滚动；0 表示不停止。

勾选好后点「发送已批准」→ 确认弹窗 → 插件按随机间隔逐条打开小窗口发送，可随时「停止发送」。没勾选的草稿不会发出。

注意：自动浏览需要 x.com 标签页**保持在前台可见**，切到后台会自动暂停。

## 回复后自动点赞

设置页「发送」里的「回复成功后自动给原帖点赞」默认开启，不需要可以关掉。已经赞过的帖子不会再点（避免变成取消点赞），点赞失败不影响回复结果。

## 已回复记录

- 通过插件发出的回复，以及填入后由你手动点「回复」的帖子，都会被记住（最多 3000 条），按钮显示「✓ 已回复」，自动浏览不会再为它们生成草稿。
- 有每日回复上限，设置页可以看到今日数量、清空记录。

## 省 token 的做法

- 默认回复上限 25 字，`max_tokens` 随之限制在约 70。
- 生成之前先在本地过滤：广告、自己的帖子、少于 15 字的帖子、已回复的、不含关键词的都直接跳过，不调用 API。
- 上下文只发精简信息：作者、正文（≤400 字）、引用帖（≤150 字）、图片 alt 文字或「N 张图片」、链接卡片标题（≤80 字）。
- system prompt 固定不变，便于命中 DeepSeek 的前缀缓存（缓存命中的输入更便宜）。
- 推荐用 `deepseek-chat`；`deepseek-reasoner` 的思考过程也会计费。

## 稳定性

- 扩展重载后旧页面会提示「请刷新页面」，不会静默失效。
- API 请求有超时，遇到网络错误、429、5xx 自动重试一次；Key 无效或余额不足时停止自动浏览。
- 页面元素选择器集中放在 `content.js` 顶部的 `SEL` 里，X 改版时只改那里。
- 页面变化监听做了节流；标签页在后台或打开弹窗时自动暂停滚动。

## 使用风险

批量回复、自动点赞属于自动化操作，可能违反 X 的使用规则，导致账号被限流或封禁。请保守设置每日上限和发送间隔，风险自负。

## 文件

| 文件 | 作用 |
|---|---|
| `defaults.js` | 共用默认设置 |
| `background.js` | DeepSeek 调用、已回复记录、批量发送窗口 |
| `content.js` | 按钮、面板、自动浏览、草稿、自动点赞 |
| `content.css` | 样式（跟随系统深色模式） |
| `options.html/js` | 设置页 |
